Key finding

XGBoost caught about 85% of fraud with just 1.6 alerts per 1,000 transactions, and SHAP shows why each alert was raised.

Read with care

The data is a public European credit-card dataset with anonymised features (V1–V28), so SHAP describes model behaviour, not the causes of fraud. No South African retirement-fund data was available, so the 0.39 threshold and these results must be validated locally before any use.
